개인정보 처리방침

GoLog 은 개인정보 보호를 가장 중요하게 생각합니다.
어떤 개인 정보나 이동 데이터를 수집·업로드·저장하지 않습니다.
모든 발자취 데이터는 기기 내에만 저장되며, 모든 기능과 분석도 로컬에서 처리됩니다.

GoLog 는 서버를 두지 않으며, 계정 시스템이나 중앙 집중식 저장도 없습니다.

데이터 처리 안내

이동 기록, 재생, 체류 분석 등 모든 처리는 기기 내에서 완료됩니다.
이동 데이터가 서버로 전송되거나, GoLog 나 제3자가 접근하는 일은 없습니다.

데이터에 대한 통제권은 언제나 사용자에게 있습니다.

회원가입이나 제3자 연동 불필요

GoLog 는 계정 등록 없이 사용할 수 있습니다.
제3자 서비스와 연동하지 않으며, 데이터를 제3자 앱이나 플랫폼에 공유하지 않습니다.

소셜 로그인, 제3자 분석 SDK, 외부 데이터 API 를 포함하지 않습니다.

개인 정보와 민감 정보

GoLog 는 핵심 기능을 위해 위치 정보만 사용합니다.
위치 정보를 제외한 개인 정보나 민감 정보는 읽거나 수집·처리하지 않습니다.

위치 정보는 발자취 기록을 위해서만 사용되며, 기기 내에 저장됩니다.

위치 정보 사용 안내

이용 중에는 이동 경로를 정확히 기록하기 위해 지속적으로 위치 정보를 사용합니다.
포그라운드·백그라운드 모두에서 위치를 사용하는 것은 정상 동작에 필요합니다.

모든 위치 정보는 기기 내에만 저장되며, 서버로 업로드되거나 GoLog 가 접근하지 않습니다.

iCloud 백업 및 동기화

GoLog 는 Apple 의 iCloud 파일 시스템을 통한 선택적 백업·동기화를 지원합니다.
iCloud 를 켜면 데이터는 GoLog 전용 폴더에만 저장되며, 업로드·동기화는 iCloud 가 수행합니다.

GoLog 가 접근할 수 있는 것은 이 전용 공간뿐이며, iCloud 의 다른 내용에는 접근하지 않습니다.
GoLog 는 이 백업 데이터를 열람·관리·통제할 수 없습니다.

민감 데이터 보호

GoLog 는 서버가 없기 때문에 민감 데이터는 항상 기기나 개인 iCloud 공간에만 남습니다.
기록·분석·정리·백업 과정에서도 서버로 정보를 전송하지 않습니다.

데이터 관리 및 삭제

GoLog 는 서버에 사용자 데이터를 보관하지 않습니다.
기기나 iCloud 파일 시스템에서 언제든 데이터를 관리·내보내기·삭제할 수 있으며, 전적으로 사용자가 결정합니다.
